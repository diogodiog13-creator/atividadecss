Sintaxe e Seletores CSS

Uma regra CSS é composta por um seletor, propriedades e valores definidos entre chaves.

Os seletores indicam qual tag HTML será estilizada, como seletores por elemento (ex: h1, p), por ID (#header) ou por classe (.destaque).
