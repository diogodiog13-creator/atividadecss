Projeto Web: Layout de Duas Colunas e Navegação CSS

Este projeto é uma aplicação web desenvolvida como atividade prática para a disciplina de Desenvolvimento Front-End para Web do curso de Ciência da Computação no UNIPÊ (Centro Universitário de João Pessoa), sob orientação do Prof. Israel Cunha.

O objetivo principal é construir uma estrutura tableless utilizando HTML5 semântico e estilização CSS externa, implementando uma navegação completa de 5 páginas focadas no ensino de conceitos básicos e avançados de CSS.

📸 Demonstração do Layout

O layout segue o padrão clássico com cabeçalho, menu lateral flutuante (float: left), área de conteúdo principal com margem adaptada e rodapé com limpeza de fluxo (clear: sboth).

Cabeçalho/Rodapé: Estilizados em tom Azul Meia-Noite (#001F3F) para alto contraste e legibilidade.

Navegação: Links interativos em cada uma das 5 páginas.

📁 Estrutura de Arquivos

A estrutura do projeto no repositório/VS Code está organizada da seguinte maneira:

├── estilos.css      # Folha de estilo CSS compartilhada
├── index.html       # Página 1 - Introdução ao CSS
├── pagina2.html     # Página 2 - Sintaxe e Seletores
├── pagina3.html     # Página 3 - Cores e Unidades
├── pagina4.html     # Página 4 - Modelo de Caixa (Box Model)
└── pagina5.html     # Página 5 - Layout e Posicionamento


🚀 Conteúdo das Páginas

index.html (Menu Item 1): Introdução ao CSS e seu papel na separação entre conteúdo e estilo visual.

pagina2.html (Menu Item 2): Definição de regras CSS, estrutura de sintaxe e tipos de seletores.

pagina3.html (Menu Item 3): Aplicação de cores em notação Hexadecimal e unidades de medida (px).

pagina4.html (Menu Item 4): Conceito de Box Model (Conteúdo, Padding, Border e Margin).

pagina5.html (Menu Item 5): Estilização de layouts, uso de float, margin-left e a propriedade clear.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação através de tags semânticas e divisões (<div>).

CSS3: Estilização com seletores por ID (#header, #menu, #main, #footer), regras de flutuação e tipografia.

VS Code: Ambiente de desenvolvimento integrado.
